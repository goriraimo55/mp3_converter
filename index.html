MP4・WebMをMP3に変換

動画ファイルをこのページに入れるだけ。ファイルは端末内だけで処理され、サーバーへ送信されません。

変換するファイル

ファイルを選択してください。

    使い方と注意

    • このフォルダをそのまま保存し、index.html をブラウザで開くだけで使えます。
    • 変換はブラウザ内のデコードと同梱のMP3エンコーダ（LAME のJavaScript移植版 lamejs）で行うため、完全にオフラインで動作します。
    • Chrome / Edge / Firefox / Safari など、主要なブラウザでそのまま変換できます。
    • 数百MB・1時間級のファイルにも対応しています（60分の動画で数分程度かかります。進捗はバーで確認できます）。
