# Offline MP3 Converter

MP4 / WebM ファイルをブラウザ上で MP3 に変換する、ビルド不要の静的アプリです。

## 使い方

1. このリポジトリをダウンロードします。
2. `index.html` をブラウザで開きます。
3. `.mp4` または `.webm` ファイルをドロップして、ビットレートを選び、変換します。

## 特徴

- ビルド不要: HTML / CSS / JavaScript だけで構成されています。
- オフライン: 変換処理はブラウザ内で完結します。
- プライベート: ファイルをサーバーにアップロードしません。

## 注意

MP3 の生成にはブラウザの `MediaRecorder` が `audio/mpeg` または `audio/mp3` をサポートしている必要があります。未対応ブラウザではエラーメッセージを表示します。
