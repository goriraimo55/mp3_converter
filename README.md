# Offline MP3 Converter

MP4 / WebM ファイルをブラウザ上で MP3 に変換する、ビルド不要の静的アプリです。

## 使い方

1. このリポジトリをダウンロードします。
2. `index.html` をブラウザで開きます。
3. `.mp4` または `.webm` ファイルをドロップして、ビットレートを選び、変換します。

## 特徴

- ビルド不要: HTML / CSS / JavaScript だけで構成されています。
- オフライン: 変換処理はブラウザ内で完結します。
- プライベート: ファイルをサーバーにアップロードしません。

## 対応ブラウザ

MP3 の生成には同梱の [lamejs](https://github.com/zhuker/lamejs)（[LAME](https://lame.sourceforge.net) の JavaScript 移植版、LGPL）を使うため、Chrome / Edge / Firefox / Safari など主要なブラウザでそのまま動作します。ブラウザの `MediaRecorder` が MP3 に対応している必要はありません。

変換は通常、ファイルを一括デコードして高速に行います。ブラウザが一括デコードできないファイルの場合は、動画を等倍速で再生しながら音声を取り込む方式に自動的に切り替わります（この場合は動画の長さと同じ時間がかかります）。
